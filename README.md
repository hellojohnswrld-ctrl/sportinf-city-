# AI Wager V2 — Render Ready

AI Wager is a football-first sports match analysis platform.

V2 adds:
- Render-ready FastAPI deployment
- /health and /api/health endpoints
- API-Football adapter
- TheSportsDB fallback adapter
- transparent baseline probability model
- odds implied probability and value/edge
- prediction logging
- simple browser dashboard
- CORS support
- environment-based API keys
- Render Blueprint configuration

Important: this is an analysis and value-estimation system, not a guarantee of winning bets or profit.
